[`snapshot.json`](snapshot.json) содержит происхождение снимка и SHA-256 каждого PNG. Хеши относятся к сохранённым снимкам; они не удостоверяют оригинальный PDF или авторство организаторов.

[`brief.txt`](brief.txt) — нормализованная текстовая транскрипция первоначального извлечения. При расхождении текста со снимками ориентироваться на снимки. Более позднее официальное уточнение организаторов имеет приоритет над этим снимком; такие уточнения нужно сохранить отдельно и связать с изменёнными требованиями.

Полный набор фиксированных проверок, обещанный в кейсе, в этих шести страницах не приведён. Наши локальные проверки не являются официальным набором.
