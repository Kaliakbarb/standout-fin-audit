# Сохранённый релиз 0.6.0: Linux amd64

**Команда Standout. Граница исходников:** ZIP0.6.0 зафиксирован до последнего обновления дизайна и интерактивной лаборатории исправлений. Текущий GitHub-код содержит более новые изменения; для их автономной сдачи нужна новая сборка и полный clean-run. Подробное разделение результатов — в [VERIFICATION](VERIFICATION.md).

Релиз 0.6.0 — отдельный Linux amd64 пакет с полигоном ИИ-аудиторов, лабораторией генерации и защищёнными worker. Неизменяемый ARM64-пакет 0.5.0 сохранён отдельно. Финальный offline-прогон привязан к SHA-256 точного передаваемого архива.

Чистая передача этого ZIP завершена: 994 tests passed, 0 failures/errors/skips; 48 прикладных проверок,19 isolation probes,12/12 genuine mutation kills,20 контрольных эпизодов,20 пар и80 replay. Внешний [CLEAN_ROOM_REPORT](verification/release-0.6.0/CLEAN_ROOM_REPORT.json) и [заключительный аудит](verification/release-0.6.0/FINAL_SUBMISSION_AUDIT.json) привязаны к точному архиву. Его SHA-256: `a2ec5f1302751d182c636482999950547162108a031b5151c0c825cfc22a435d`.

В пакет входят Python-модули и все пять browser assets на момент фиксации: HTML, CSS, JavaScript controller, модуль учебного разбора и модуль воспроизведения фактической траектории. Для просмотра предусмотрен `./demo --offline`, для полной проверки — `./verify --offline`.

Подготовка image и инструментов может использовать сеть. Проверка, загрузка переданного image и исполнение подготовленного пакета выполняются без внешней сети, GPU и платных API. Результаты остаются синтетическими; демонстрация использует скриптовые политики и не заявляет обучение весов модели.

Способ исполнения amd64 на этой машине указывается явно: ARM Mac и, при использовании QEMU, full-system x86_64 Linux guest. Это не заявление о физическом x86-хосте. Соответствие OCI image, ядра гостя и Python application architecture проверяется отдельно.

Исторические доказательства 0.5.0 находятся в [статусе G5](STAGE5_STATUS.md). Критерии исходного кейса и границы официальной оценки остаются в [матрице требований](REQUIREMENTS.md).
